# Amorinha Sorvetes e Açaí - Relatório Meta Ads

🍇 Site responsivo com relatório completo de desempenho de campanhas Meta Ads para Amorinha Sorvetes e Açaí.

## 📊 Recursos

- **Visão Geral**: KPIs principais, resumo executivo
- **Campanhas**: Tabela detalhada com performance de cada campanha
- **Geografia**: Distribuição geográfica do alcance e investimento
- **Gráficos Interativos**: Chart.js com análises visuais
- **Insights**: Pontos de atenção com recomendações estratégicas
- **Responsivo**: Design mobile-first, otimizado para todos os dispositivos
- **Animações**: AOS (Animate On Scroll) para uma experiência fluida

## 🚀 Como usar

1. Clone o repositório
2. Abra `index.html` no navegador
3. Navegue pelas seções usando o menu

## 📁 Arquivos

- `index.html` - Estrutura HTML com logo SVG integrada
- `styles.css` - Estilos responsivos com variáveis CSS
- `script.js` - Gráficos interativos e animações

## 🎨 Design

- Cores: Roxo (#534AB7), Verde/Teal (#1D9E75), Âmbar (#BA7517)
- Fonte: Helvetica Neue
- Layout: CSS Grid e Flexbox
- Animações: Smooth scroll, fade-up, zoom-in

## 📱 Responsividade

- Desktop: 1200px
- Tablet: até 768px
- Mobile: até 480px
